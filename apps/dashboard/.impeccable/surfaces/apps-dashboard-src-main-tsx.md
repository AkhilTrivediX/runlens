# Dashboard surface

Mode: Operate. Target: apps/dashboard/src/main.tsx and apps/dashboard/src/styles.css.

## Direction contract

THESIS: An investigation instrument for browser automation. A run ledger controls the trace inspector. Selection connects duration, failure, selector and browser evidence.

OWN-WORLD: Self hosted Bricolage Grotesque carries the product identity. A white top navigation sits above a warm grey workspace. Plum history instrumentation uses mint and pink timing bars. Violet marks selection and action. The ledger and inspector share a continuous frame.

STORY: Find a run using status, project and search. Follow the execution waterfall. Select a step to reveal error, selector, screenshot and events. Review signals and all evidence in separate sections.

FIRST VIEWPORT: A horizontal product header frees the workspace width. The 52px Trace the fault heading and inline health measures sit beside a plum duration history instrument. A 330px ledger joins a wide inspector below the filters. Refresh and optional polling remain explicit.

FORM: Laboratory instrument front panel, candidate 4 of seven grounded systems. Seed 08abbc8d. The other grounded systems were debugger panes, performance profilers, batch logs, incident dossiers, dispatch boards and film contact sheets. The run uses a direct implementation. No user workflow default is persisted.

Signature interaction: selecting a measured step changes its evidence and events without losing the surrounding execution context.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## User revision

The user rejected the initial system font and generic interface style. This revision replaces both. Anthropic frontend design guidance informed the subject specific typography and layout. No Claude model was executed. The previous visual world is superseded.
