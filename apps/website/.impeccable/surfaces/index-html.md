## Motion and interaction revision

User rejected the static first version as too basic. Preserve the established visual world and product truth. The focal sequence replays navigation, click and failure with advancing duration fills, selected context and a captured evidence reveal. Visitors can pause, resume or interrupt with a manual selection. Autoplay occurs once while visible, stops offscreen or when the document is hidden and is disabled for reduced motion. Three failure scenarios update the classification, event and DOM evidence. Evidence and integration tabs support arrow keys, Home and End. A single local capture path animation links automation to SQLite to dashboard on viewport entry. Default content remains fully visible without JavaScript. No comp or raster asset.
