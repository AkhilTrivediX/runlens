pnpm build

pnpm test:playwright
pnpm start:dashboard
Open http://127.0.0.1:5173 after the server starts.

A few things to know.

Does RunLens replace Playwright or Puppeteer?

No. RunLens instruments your existing workflow. Use the browser tools you already have and wrap the meaningful actions in RunLens steps.

Can I install it from npm?

The 0.1.0 package is being prepared for release. For now, build from the source using the quickstart above. The repository has instructions for packing and installing the SDK locally.

What gets captured?

Runs, steps, timing, selectors, browser events and classified failures. Browser adapters collect console and page errors plus failed requests. With debugger mode and a page context provider, RunLens can capture screenshots and DOM snapshots on failure.

Is this a hosted dashboard?

This website introduces the product. The RunLens dashboard runs locally and reads your SQLite trace store. Your local runs are not sent to this website.
